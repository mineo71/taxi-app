# Функціональні вимоги

Функціональні вимоги описують, **що** робить система. Вимоги згруповані за ролями користувачів.

Пріоритет за методом MoSCoW: **Must** — без цього MVP не запускається, **Should** — важливо, але можна запустити без цього, **Could** — бажано, переноситься на наступні релізи.

## Пасажир

| Код | Вимога | Пріоритет |
|---|---|---|
| FR-1 | Реєстрація та вхід за номером телефону з одноразовим кодом, а також через Google або Apple ID | Must |
| FR-2 | Профіль: ім'я, фото, збережені адреси, способи оплати | Should |
| FR-3 | Визначення місцезнаходження через GPS і ручний вибір точки подачі на карті | Must |
| FR-4 | Введення адреси призначення з автопідказками та проміжними зупинками | Must |
| FR-5 | Вибір класу авто з попереднім розрахунком вартості | Must |
| FR-6 | Додаткові побажання: дитяче крісло, перевезення тварин, коментар водієві | Should |
| FR-7 | Попереднє замовлення на конкретний час | Could |
| FR-8 | Підвищення ціни для швидшого пошуку водія в пікові години | Could |
| FR-9 | Скасування замовлення зі штрафом після певного часу | Must |
| FR-10 | Відстеження водія на карті та орієнтовний час подачі | Must |
| FR-11 | Дані про водія й авто: ім'я, фото, рейтинг, марка, колір, номер | Must |
| FR-12 | Дзвінок і чат через маскований номер | Should |
| FR-13 | Поділитися поїздкою з близькими та кнопка SOS | Should |
| FR-14 | Сповіщення про ключові події поїздки | Must |
| FR-15 | Оплата готівкою, карткою, Apple Pay, Google Pay або корпоративним рахунком | Must |
| FR-16 | Промокоди, бонуси, кешбек | Could |
| FR-17 | Оцінка водія, відгук і чайові | Must |
| FR-18 | Історія поїздок з електронними чеками | Must |
| FR-19 | Звернення в підтримку щодо конкретної поїздки | Should |

## Водій

| Код | Вимога | Пріоритет |
|---|---|---|
| FR-20 | Реєстрація з верифікацією документів і модерацією | Must |
| FR-21 | Статус «на лінії» та «не на лінії» | Must |
| FR-22 | Отримання пропозицій замовлень з обмеженим часом на відповідь | Must |
| FR-23 | Навігація до пасажира та за маршрутом | Must |
| FR-24 | Зміна статусів поїздки: на місці, почати, завершити | Must |
| FR-25 | Фіксація очікування та платного простою | Should |
| FR-26 | Баланс, історія заробітку, комісія, виведення коштів | Must |
| FR-27 | Рейтинг водія та оцінка пасажира | Should |
| FR-28 | Фільтри замовлень: радіус, напрямок, тип оплати | Should |

## Адміністратор і система

| Код | Вимога | Пріоритет |
|---|---|---|
| FR-29 | Модерація документів водіїв, блокування, перевірка скарг | Must |
| FR-30 | Налаштування тарифів за містом, класом авто, часом доби | Must |
| FR-31 | Моніторинг активних поїздок і водіїв на карті | Must |
| FR-32 | Обробка звернень, повернення коштів, розв'язання спорів | Should |
| FR-33 | Керування промоакціями та промокодами | Could |
| FR-34 | Аналітика: замовлення, конверсія, відтік, дохід, теплова карта попиту | Should |
| FR-35 | Алгоритм розподілу замовлень за відстанню, рейтингом і рівнем прийняття | Must |
| FR-36 | Динамічне ціноутворення залежно від попиту й пропозиції | Should |
| FR-37 | Розрахунок фінальної вартості за фактичним маршрутом і простоєм | Must |
| FR-38 | Антифрод: фейкові GPS-координати, мультиакаунти, зловживання промокодами | Could |

## Скорочений перелік

Реєстрація та вхід, замовлення поїздки, показ ціни перед замовленням, підбір водія, скасування, відстеження авто на карті, дані про водія, зв'язок з водієм, оплата, оцінка поїздки, історія поїздок, підтримка, кабінет водія, адмін-панель.
